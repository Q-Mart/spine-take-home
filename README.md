# Take Home Task - Qumarth Jash
Here is a brief overview of the structure of this repository:
- `Design.md` - Main design document
- `chargecycles` - source code for main service that is responsible for business logic in this domain
  - This should be able to run as a spring boot application via IntelliJ
  - I unfortunately ran out of time before I could containerise the application
- `permissions` - API spec for the "Permissions" service
- `service-registry` - API spec for the mock Service Registry
- `tickets` - Change request tickets for the upstream API, as well as an updated API spec that contains said changes
- `utils` - Utility classes that I imagine will be shared between services
